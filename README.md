# 🚗 Apex Detail — Демо-бот детейлинг-центра для Telegram

Профессиональный Telegram-бот для студии детейлинга, разработанный на **Python 3** и фреймворке **aiogram 3.x**. 

Бот автоматизирует привлечение клиентов, рассчитывает точную стоимость услуг в 2 клика с учетом класса авто, демонстрирует примеры работ («До / После») и захватывает контакты с бонусом («Антидождь в подарок»).

---

## 📱 Сценарии и экраны бота

1. **Экран 1: Приветствие (`/start`)**
   - Брендовое приветствие детейлинг-центра.
   - Главное меню: инлайн-кнопки + постоянная нижняя клавиатура для быстрого доступа.
2. **Экран 2: Интерактивный калькулятор стоимости**
   - **Шаг 1:** Выбор класса автомобиля (*Малый/Средний*, *Бизнес/Кроссовер*, *Внедорожник/Минивэн*).
   - **Шаг 2:** Выбор услуги (*Глубокая полировка*, *Детейлинг-химчистка*, *Защита керамикой 9H*, *Комплекс 'All Inclusive'*).
   - **Шаг 3:** Расчет стоимости с коэффициентом кузова (например, для кроссовера +20%, внедорожника +40%) и сроков выполнения.
   - **Лид-магнит и захват:** Скидка + подарок («Антидождь на лобовое стекло»). Быстрая отправка номера телефона через кнопку `[ 📲 Отправить номер телефона ]` в один клик.
3. **Экран 3: Портфолио («До / После»)**
   - Наглядные карточки работ с разделителем «До / После» (полировка царапин, химчистка кожи, гидрофоб керамики).
   - Под каждым фото кнопка: `[ ✨ Хочу так же — Рассчитать стоимость ]` (сразу открывает калькулятор с предвыбранной услугой).
4. **Экран 4: Адрес и контакты**
   - Адрес, график работы, телефон, канал студии.
   - Прямая ссылка на **Яндекс.Карты** (`[ 🗺 Открыть на Яндекс.Картах ]`).
5. **Экран 5: Полный прайс-лист**
   - Структурированные тарифы по всем категориям и дополнительным услугам (бронепленка, фары, антидождь).
6. **Экран 6: Консультация мастера**
   - Прямая ссылка на диалог с мастером в Telegram, кликабельный телефон и возможность задать вопрос прямо в боте.

## 🚀 Быстрый запуск

### 1. Установка окружения (если запускаете вручную)

```bash
# Перейдите в папку проекта
cd detailing_bot

# Создайте виртуальное окружение
python3 -m venv venv

# Активируйте окружение
source venv/bin/activate  # на Linux / macOS
# venv\Scripts\activate    # на Windows

# Установите зависимости
pip install -r requirements.txt
```

### 2. Настройка `.env`

Создайте или отредактируйте файл `.env`:
```ini
BOT_TOKEN=9003520012:AAHzrGHBqME4R_dQxc_0hdUoenmOfy_i9Fo

# Укажите ваш цифровой Telegram ID для получения уведомлений о заявках клиентов
# (Узнать свой ID можно через бота @userinfobot в Telegram)
ADMIN_TELEGRAM_ID=123456789

COMPANY_NAME=Apex Detail
COMPANY_PHONE=+7 (999) 000-00-00
COMPANY_ADDRESS=г. Москва, ул. Примерная, 15 (бокс 4)
COMPANY_WORK_HOURS=Ежедневно с 10:00 до 21:00 (по предварительной записи)
COMPANY_CHANNEL=@channel
YANDEX_MAPS_URL=https://yandex.ru/maps/?text=Москва,+ул.+Примерная+15
MASTER_USERNAME=apex_master
```

### 3. Запуск бота

```bash
python main.py
```

## 🌐 Варианты хостинга (24/7)

1. **Сервер VPS (Ubuntu/Debian, от 100-150 руб./мес)**:
   - Клонируйте проект на сервер.
   - Настройте `systemd` сервис для автозапуска:
     ```ini
     [Unit]
     Description=Apex Detail Telegram Bot
     After=network.target

     [Service]
     User=root
     WorkingDirectory=/root/detailing_bot
     ExecStart=/root/detailing_bot/venv/bin/python main.py
     Restart=always

     [Install]
     WantedBy=multi-user.target
     ```
2. **Бесплатный облачный хостинг (Railway / Render / Amvera)**:
   - Создайте репозиторий на GitHub.
   - Подключите к Railway или Render, указав команду запуска `python main.py` и добавив переменную `BOT_TOKEN` в Environment Variables.
